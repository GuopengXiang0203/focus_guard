# 专注守护 (Focus Guard)

一款简洁的 iOS 专注 App，帮助用户在设定的时间区间内保持专注。

## 功能特点

- ⏰ **时间设置** - 简单设置专注开始和结束时间
- 🔒 **引导式访问** - 一键引导用户开启 iOS 引导式访问
- 📱 **强制专注** - 开启后手机只能使用当前 App
- ⌨️ **轻松退出** - 三击电源键退出专注模式

## 使用方法

### 1. 设置专注时间
- 打开 App，点击开始/结束时间
- 选择你的专注时间段

### 2. 开启专注模式
- 点击「开始专注」按钮
- 按照提示开启 iOS 引导式访问：
  1. 打开「设置」→「辅助功能」
  2. 点击「引导式访问」
  3. 开启「引导式访问」
  4. 设置密码

### 3. 退出专注
- 三击电源键 → 输入密码 → 点击「结束」

## 技术栈

- **框架**: Flutter 3.x
- **构建**: Codemagic
- **目标平台**: iOS

## 开发

```bash
# 获取依赖
flutter pub get

# 运行调试
flutter run

# 构建 iOS
flutter build ipa --release
```

## 上传到 App Store

1. 注册 Apple Developer 账号
2. 在 Codemagic 配置 App Store Connect API 密钥
3. 推送代码到 GitHub
4. Codemagic 自动构建并上传

## 注意事项

- 本 App 需要在 iOS 设备上运行
- 引导式访问是 iOS 系统功能，需要用户手动开启
- 退出需要输入设置的密码
